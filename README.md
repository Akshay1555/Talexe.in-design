# Talexe.in — Next.js landing page

A responsive Next.js recreation of the supplied Talexe.in career-guidance design.

## Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes
- App Router structure.
- Responsive desktop/tablet/mobile layout.
- Dark navy + gold visual system.
- Hero portrait is cropped from the user-provided reference screenshot.
- Navigation, services, pricing and contact sections are included.
- Replace `public/hero-career.jpg` with a licensed/original portrait if you have one.
